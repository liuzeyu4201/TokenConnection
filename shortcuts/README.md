# iOS 快捷指令「记人脉」

手机上的录入入口（design.md §12）：把一句话 POST 到 `/api/v1/inbox`，服务端立刻解析成草稿放进收件箱；确认动作留在 web 上做。手机只负责「记下来」，零摩擦。

## 前置

1. Mac 上 `pnpm dev` 正在运行，并且手机能访问到它：
   - **同一 Wi-Fi**：用 `pnpm dev` 打印的 `Network: http://192.168.x.x:3000` 这个地址（也可在 Mac 的「系统设置 → Wi-Fi → 详细信息」里看 IP）。路由器重启后 IP 可能变化，建议在路由器里给 Mac 固定 IP。
   - **不在同一网络**：装 [Tailscale](https://tailscale.com/)，Mac 和 iPhone 登录同一账号，用 Mac 的 Tailscale 地址（形如 `http://100.x.y.z:3000` 或 MagicDNS 名 `http://<mac-name>.tail1234.ts.net:3000`）。
   - 上服务器后换成域名（阶段 3）。
2. `.env` 里的 `API_TOKEN`。

下文用 `<host>` 代表 `http://192.168.x.x:3000` 这样的地址，`<token>` 代表 `API_TOKEN`。

## 配置步骤（快捷指令 App）

新建快捷指令，命名为「记人脉」，依次添加以下动作：

1. **接收输入**
   - 点顶部的快捷指令名 → 「详情」→ 打开「在共享表单中显示」，接受类型选「文本」。
   - 在「快捷指令输入」这一项里设置：如果没有输入，则「要求输入」→ 类型「文本」，提示语「记一个人，或追加一句」。这样从分享菜单进来时直接用分享的文本，从主屏幕 / Siri 进来时弹输入框（可以直接用听写）。
2. **获取 URL 内容**（动作名「获取 URL 内容」）
   - URL：`<host>/api/v1/inbox`
   - 方法：`POST`
   - 头部：新增一项，键 `Authorization`，值 `Bearer <token>`（注意 Bearer 后有一个空格）。
   - 请求体：`JSON`，添加两个字段：
     - `raw_text`（文本）→ 选择变量「快捷指令输入」
     - `source`（文本）→ `shortcut`
3. **从输入获取词典值**（可选，用于显示结果）
   - 作用于上一步的「URL 内容」，获取 `draft` 的值；再一次「获取词典值」取 `person`，再取 `name`、`summary`、`location`。
   - 简单做法：直接用一个「获取词典值」取键 `draft.person.name`（快捷指令支持点号路径），再取 `draft.person.summary` 和 `draft.person.location`。
4. **显示结果**（或「显示通知」）
   - 文本：`已记录：<name> / <summary> / <location>`，三个都是上一步的变量。
   - 如果不想折腾解析，第 3、4 步可以合并成一句「显示通知：已记录，回电脑确认」。

## 使用

- 在任何 App 里选中一段文字 → 分享 → 「记人脉」；或者在主屏幕点快捷指令图标 → 弹输入框 → 说一句「今天球馆认识小王，羽毛球教练，深圳，微信 wx123，人很热情」。
- 也可以对 Siri 说「记人脉」。
- 回到电脑（或手机浏览器）打开首页，「待处理」里就有一张草稿卡，改一改点「确认入库」。
- 想直接查人，句首加 `?`：`?想找个人教我打羽毛球`。想强制记录，句首加 `+`。

## 排查

| 现象 | 原因与处理 |
| --- | --- |
| 请求超时 / 无法连接 | 手机和 Mac 不在同一网络或 IP 变了；确认 `pnpm dev` 在跑，并且是监听 `0.0.0.0`（Next 默认如此）；Mac 防火墙放行 node |
| 返回 `{"error":{"code":"unauthorized"...}}` | 头部 `Authorization` 写错，或 `.env` 里的 `API_TOKEN` 改过没重启 |
| 返回 `validation_error` | 请求体不是 JSON 或 `raw_text` 为空；确认请求体类型选的是 JSON 而不是「表单」 |
| 记录成功但草稿字段都是空的 | LLM 不可用或解析失败，inbox 里会带 `error`；回电脑用空表单手动填写即可，原文已保留在摘要里 |
